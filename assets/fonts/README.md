# assets/fonts

Opcjonalny dołączony font TrueType/OpenType (licencja SIL OFL lub kompatybilna z MIT).
Jeśli w tym katalogu znajduje się plik *.ttf/*.otf, będzie użyty zamiast systemowego Ariala,
co zapewnia identyczny wydruk polskich znaków na macOS i Windows.

Przykład: LiberationSans-Regular.ttf (SIL OFL) lub DejaVuSans.ttf.
